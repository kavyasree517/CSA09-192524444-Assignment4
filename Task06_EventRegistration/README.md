# Task 06 – Event Registration Application

## Requirements
- Student enters registration number and name.
- Select event and register.
- Validate form inputs.
- Prevent duplicate registration.
- Display records in a table.
- Filter by event.
- Export CSV.
- Use SwingWorker for database operations.
